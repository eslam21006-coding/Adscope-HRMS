# Adscope HRMS — English UX Update

This build replaces raw JSON and database messages with clear English across:

- Payroll readiness checks
- Attendance month generation
- Payroll workflow actions
- Violation finalization
- Payroll calculation details
- Common permission and login errors

## Update the live site

1. Extract the ZIP.
2. Double-click `UPDATE-LIVE-SITE.bat`.
3. If Vercel asks to link a project, choose the existing Adscope HRMS project. Do not create a new project.
4. After deployment completes, reopen `https://hrms.adscope.net/admin/` and refresh.

No Supabase changes are required for this update.
